# 📈 STOCK VERCE TRADE HUB

A full-stack MERN based stock trading and portfolio management platform that allows users to explore market trends, manage virtual investments, track portfolio performance, and experience a real-world trading workflow in a secure learning environment.

---

# 🚀 Project Overview

STOCK VERCE TRADE HUB is a modern stock market web application developed as an 8th semester major project using the MERN Stack.

The application is designed to simulate the experience of a real trading platform where users can:

- Explore stock market data
- Buy and sell virtual stocks
- Track investment performance
- Monitor holdings and positions
- Manage portfolios efficiently
- Understand stock trading concepts in a practical way

This project combines frontend development, backend APIs, authentication, database management, and deployment into one complete full-stack application.

# ❓ Problem This Project Solves

Many beginners want to learn stock trading and portfolio management but feel afraid of investing real money initially.

This platform provides a safe virtual environment where users can:

- Understand stock market workflows
- Practice trading concepts
- Learn portfolio management
- Track profits and losses
- Gain confidence before entering real-world investing

without financial risk.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Jagrati3/Stock_Verse_Trade_Hub.git
```

---

## 2️⃣ Setup Backend

```bash
cd backend
npm install
npm start
```

---

## 3️⃣ Setup Frontend

```bash
cd frontend
npm install
npm start
```

---

## 4️⃣ Setup Dashboard

```bash
cd dashboard
npm install
npm start
```

---

# 🔑 Environment Variables

Create `.env` file inside backend folder.

Example:

```env
PORT=5000
MONGO_URL=your_mongodb_connection
JWT_SECRET=your_secret_key
```
